# The help-centre tree — help.fieldquo.com

The spine is `lib/help/tree.js`: fourteen real categories plus two virtual
ones (Only in FieldQuo, Videos), one slug per article, in the order the
pages show them. Words live in `content/help/{en,fr,es}/<category>.js`;
this file is the coverage review. The table at the bottom is regenerated by
`npm run build:help` (✓ = written in that language).

URL: `/help/{lang}/{category}/{article}` — `help.fieldquo.com/en/invoices-and-payments/payment-processing-fees-and-payouts`.
